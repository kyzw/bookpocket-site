Book Pocket プライバシーポリシー

制定日・最終改訂日：2026年11月17日

Book Pocket の開発者は、本棚を管理する Web サービス Book Pocket（以下「本サービス」）におけるデータの取り扱いを、以下のとおり定めます。本サービスは、本人用に事前作成されたアカウントでログインし、複数の端末から同じ本棚を利用するためのサービスです。

1. 取得・保存する情報と利用目的

  • 書籍タイトル、作者名、読書の状態（読んでる・積読・読んだ・読みたい）、読了巻数、最新巻数：本棚の保存・表示・検索・編集・削除、読書進捗の管理に使用します。
  • 書籍ごとの内部管理ID、所有者のユーザーID、作成日時、更新日時、読了日時：書籍と所有者の識別、アクセス制御、一覧の並び順、保存・更新の管理に使用します。
  • メールアドレス、パスワードによる認証情報、ユーザーID、セッション情報：ログイン、本人の確認、ログイン状態の復元・更新に使用します。

本棚内のタイトル・作者名検索は、取得済みの本棚をブラウザ内で絞り込んで行います。その検索語をデータベースに保存したり、外部の検索サービスへ送信したりしません。ただし、本棚の取得・保存・更新・削除には、次に記載する Supabase との通信が発生します。

2. サーバーへの送信と保存先

本棚の情報と認証に必要な情報は、データ保存・認証の基盤である Supabase に送信・保存します。メールアドレスとパスワードはログイン時に Supabase Auth へ送信します。Supabase Auth はパスワードをハッシュとして保管します。本サービスのアプリ側で、平文パスワードを永続保存したりログに出力したりしません。

本人用アカウントは管理者が事前に作成します。一般向けのアカウント登録画面や匿名認証は提供していません。本棚への通常のアクセスは、ログインした所有者に限定する設定を行います。開発者は、サービスの保守・障害対応・削除対応などに必要な範囲で、管理権限により保存データを取り扱う場合があります。

本サービスのファイルとこのポリシーは GitHub Pages で配信します。サイトへのアクセス時には、GitHub がセキュリティ目的でIPアドレスを記録・保存します。Supabase との通信でもIPアドレス等の接続情報が通信先に伝わり、サービスの運用や安全確保のために処理される場合があります。

各提供元の取り扱いについては、Supabase のプライバシーポリシー、Supabase のデータ処理条件、GitHub のプライバシーに関する声明も参照してください。

3. ブラウザへの保存

ログイン状態の復元・更新のため、Supabase の認証ライブラリがセッショントークンやユーザーID・メールアドレス等のセッション情報をブラウザの localStorage 等に保存します。また、PWA として表示・更新するため、アプリのファイルやアイコン等をブラウザのキャッシュに保存します。本棚データの保存先は Supabase であり、オフラインで本棚を保存する機能はありません。

共有端末では、利用後にログアウトしてください。端末上のサイトデータやキャッシュはブラウザの設定から消去できますが、この操作やPWAの削除によって、サーバー上の本棚やアカウントが削除されることはありません。

4. 外部サービス・広告・分析

現在、外部書籍API、広告、利用状況分析、クラッシュ情報収集のための外部SDKやトラッキング機能は導入していません。本棚の表示に外部の書影画像を取得することもありません。サービスの提供に必要な上記の保存・認証・配信等を除き、本棚データを広告目的で第三者に提供・販売しません。

5. 保存期間・編集・削除

本棚の情報は、利用者が削除するまで Supabase に保存します。登録した書籍は、本サービスの詳細画面から編集・削除できます。削除操作が正常に完了すると、対象の書籍は稼働中のデータベースから削除されます。

ログアウトはサーバー上の本棚やアカウントを削除する操作ではありません。アカウントをアプリ内から削除する機能はありません。本人用アカウントの削除は管理者が行い、アカウントに紐づく本棚も削除します。削除に関する相談では、下記の公開窓口に個人情報や認証情報を投稿しないでください。

バックアップや運用ログの保管は、各サービスの設定や保管期間に従います。書籍・アカウントの削除操作が、バックアップや運用ログの即時消去を意味するものではありません。

6. お問い合わせ

お問い合わせは Book Pocket の公開問い合わせ窓口（GitHub Issues）へお願いします。投稿には GitHub アカウントが必要で、投稿内容は公開されます。

メールアドレス、パスワード、認証トークンなどの個人情報・認証情報、書籍一覧や個人情報を含むスクリーンショットは投稿しないでください。本人確認を要する相談でも、公開Issuesで個人情報をやり取りしないでください。利用者が任意に投稿した内容や GitHub のアカウント名は、お問い合わせへの対応と必要な連絡のために利用します。投稿の保存・編集・削除には GitHub の機能と規約が適用されます。本サービスから本棚データを自動で添付・送信することはありません。

7. ポリシーの変更

将来、楽天ブックスAPIなどの外部書籍APIを追加する場合は、検索語（タイトル・著者名・ISBN等）の送信や書影取得に伴う通信、送信先・利用目的・保存や削除の扱いを確認し、提供開始前にこのポリシーを改訂します。公開アカウント登録、広告、分析、その他のデータの取り扱いを変更する場合も、内容を見直します。

改訂内容と適用開始日は、このページでお知らせします。
