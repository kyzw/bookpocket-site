Book Pocket プライバシーポリシー

制定日：2026年11月17日

Book Pocket の開発者は、iPhone 向け Book Pocket（以下「本アプリ」）におけるデータの取り扱いを、以下のとおり定めます。このポリシーは、書籍情報を端末内に保存する MVP 版を対象とします。

1. 端末内に保存するデータと利用目的

本アプリは、利用者が入力する次の情報を、端末内の SQLite データベースに保存します。

  • 書籍タイトル
  • 読書の状態（読んでる・積読・読んだ・読みたい）
  • 読了巻数と最新巻数（巻数を管理する場合）

あわせて、書籍ごとの内部管理 ID、作成日時、更新日時を自動で保存します。これらは書籍の識別、保存・編集・削除、状態別の一覧表示、更新順の表示、アプリ再起動後の本棚の復元に使用します。内部管理 ID は端末内の書籍を区別する番号で、利用者や端末を追跡する ID ではありません。

本棚内のタイトル検索は端末内で処理します。検索語はデータベースに保存せず、外部の検索サービスへ送信しません。

2. サーバー送信と第三者への提供

本アプリは、本棚の情報、内部管理 ID、作成・更新日時、検索語を、開発者のサーバーや外部サービスへ送信しません。開発者は、利用者の端末内の本棚データを取得・閲覧しません。

MVP 版では、Supabase、アカウント作成、ログイン、匿名認証（anonymous auth）、クラウド同期、外部書籍 API を使用しません。広告、利用状況分析、クラッシュ情報収集のための外部 SDK やトラッキング機能も導入していません。本棚データを広告事業者その他の第三者へ提供・販売しません。

3. 保存期間と削除

保存した書籍情報は、利用者が本アプリの書籍詳細画面から削除するまで端末内に保持します。入力内容は本アプリ内で確認・編集できます。端末の設定から本アプリを「削除」すると、端末上の本アプリの保存データも削除されます。「App を取り除く」操作はデータを残す操作のため、データ削除とは異なります。

開発者側に本棚データのコピーはなく、開発者による復元や遠隔での削除はできません。本アプリ独自のバックアップ・同期機能はありませんが、iOS の設定によってはアプリデータが iCloud やコンピュータへの端末バックアップに含まれる場合があります。既存のバックアップの管理・削除は利用者が Apple の設定・手順に従って行ってください。

4. お問い合わせ

お問い合わせは Book Pocket の公開問い合わせ窓口（GitHub Issues）へお願いします。投稿には GitHub アカウントが必要で、投稿内容は公開されます。

メールアドレスなどの個人情報、書籍一覧や個人情報を含むスクリーンショットは投稿しないでください。利用者が任意に投稿した内容や GitHub のアカウント名は、お問い合わせへの対応と必要な連絡のために利用します。投稿の保存・編集・削除には GitHub の機能と規約が適用されます。本アプリから本棚データを自動で添付・送信することはありません。

5. ポリシーの変更

将来、クラウド同期、認証、外部書籍 API、分析、広告などを追加する場合は、送信先・送信内容・利用目的・保存や削除の扱いを見直し、提供開始前にこのポリシーと App Store のプライバシー情報を更新します。楽天ブックス API の導入時には、タイトル・著者名・ISBN などの検索語の外部送信や、書影取得に伴う通信についても見直します。

改訂内容と適用開始日は、このページでお知らせします。
